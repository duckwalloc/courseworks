The Daily Checklist project will generate a checklist from a file given by the user. 
The checklist will be printed to the screen and ask the user whether a task has been completed. 
If the task has been completed, the program will display that the task is completed. 
Until all the tasks are done, the checklist will continue to operate.
If all the tasks are completed, then the program will end with a message stating that all the tasks are done.
